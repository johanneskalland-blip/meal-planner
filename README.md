# Meal Planner

A personal Java project for building a meal planning and grocery management application.

## Project goal

The goal is to create an application that can:
- Manage recipes and ingredients
- Keep track of ingredients already available at home
- Generate shopping lists based on planned meals
- Compare grocery offers to help plan affordable meals

## Current status

The project is currently under development. The domain model for ingredients,
recipes and inventory has been implemented, together with unit tests.

## Technologies

- Java
- Maven
- JUnit 5

## Planned features

- Weekly meal planning
- Automatic shopping list generation
- Inventory and expiration date tracking
- Grocery offer integration
- Barcode scanning
